# Mosaic Creator 要件定義書

- 版数: 0.1（ドラフト）
- 作成日: 2026-11-10

## 1. 概要

画像の任意の長方形範囲にモザイク（ブロックモザイク／グレー塗りつぶし）を掛け、PNGで保存できるWebアプリ。

| 項目 | 内容 |
|---|---|
| アプリ名 | Mosaic Creator |
| リポジトリ名 | `mozaic-creator` |
| 構成 | フレームワークを使わない静的Webサイト（HTML / CSS / JavaScript） |
| 公開先 | GitHub Pages |
| 対象ブラウザ | Google Chrome 最新版（デスクトップ）のみ |
| 対象デバイス | PC のみ（スマホ・タブレットは対象外） |
| 表示言語 | 日本語のみ |
| 外部依存 | なし（ライブラリ・CDN・アクセス解析・広告を使わない） |

## 2. 機能要件

### 2.1 画像の読み込み

| ID | 要件 |
|---|---|
| F-01 | 「ファイルを選択」ボタンから画像を読み込める |
| F-02 | 画面へのドラッグ・アンド・ドロップで画像を読み込める。ドラッグ中はドロップ可能な領域を強調表示する |
| F-03 | クリップボードからの貼り付け（Ctrl+V）で画像を読み込める |
| F-04 | 対応形式は PNG / JPEG / WebP / GIF。GIFは1フレーム目のみを扱う。それ以外の形式はエラーメッセージを表示する |
| F-05 | 扱う画像は1枚ずつ。編集中に新しい画像を読み込むときは、置き換えてよいか確認ダイアログを出す（範囲が1つもなければ確認しない） |
| F-06 | EXIFの回転情報による独自の向き補正処理は行わない（ブラウザ標準のデコード結果をそのまま使う） |

### 2.2 画像の表示

| ID | 要件 |
|---|---|
| F-10 | 画像は表示領域（最大幅 960px、最大高さ 画面の高さの70%）に縦横比を保って収まるよう縮小表示する。表示領域より小さい画像は拡大しない |
| F-11 | 内部では元画像の解像度のまま保持し、表示時だけ縮小する |
| F-12 | 画像のファイル名、元のサイズ（幅×高さ px）を表示する |

### 2.3 範囲の指定と編集

| ID | 要件 |
|---|---|
| F-20 | 画像上をマウスでドラッグして長方形範囲を指定できる |
| F-21 | 範囲は複数指定できる |
| F-22 | 範囲は画像の外にはみ出さない（画像の端で切り詰める） |
| F-23 | 小さすぎる範囲（表示上 4px 未満）は作成しない（クリックの誤操作対策） |
| F-24 | 範囲をクリックすると選択状態になり、ドラッグで移動、四隅と各辺のハンドルでリサイズできる |
| F-25 | 選択中の範囲は Delete / Backspace キー、または一覧の削除ボタンで削除できる |
| F-26 | 「すべて削除」ボタンで全範囲を削除できる（確認ダイアログあり） |
| F-27 | 元に戻す（Ctrl+Z）／やり直し（Ctrl+Y、Ctrl+Shift+Z）ができる。対象は範囲の追加・移動・リサイズ・削除・設定変更 |
| F-28 | 範囲どうしが重なった場合は、後から作成した範囲を上に描画する |
| F-29 | 画面上の範囲の座標は元画像の座標に換算して保持する |

### 2.4 モザイクの種類と設定

| ID | 要件 |
|---|---|
| F-30 | モザイクの種類は「ブロックモザイク」と「グレー塗りつぶし」から選べる |
| F-31 | 種類と設定は範囲ごとに持つ。ツールバーで選んだ種類・設定が次に作成する範囲に使われる |
| F-32 | 範囲を選択中に種類・設定を変更すると、その範囲に反映される |
| F-33 | **ブロックモザイク**：ブロック内の画素の平均色で塗る。ブロックの大きさはスライダーで 4〜64px（元画像のピクセル単位）、初期値は 16px |
| F-34 | ブロックモザイクは常に元画像から計算する（重なった範囲でモザイクが二重に掛からない） |
| F-35 | **グレー塗りつぶし**：濃・中・淡の3段階から選ぶ。初期値は「中」 |
| F-36 | グレーの色は 濃 = `#505050`、中 = `#808080`、淡 = `#B0B0B0` |
| F-37 | 範囲を指定・変更した時点で、すぐにモザイクを画面に反映する（「適用」ボタンは置かない） |

### 2.5 範囲一覧

| ID | 要件 |
|---|---|
| F-40 | サイドパネルに範囲の一覧（番号、種類、設定値）を表示する |
| F-41 | 一覧の項目をクリックすると、その範囲が選択状態になる |
| F-42 | 一覧の各項目に削除ボタンを付ける |

### 2.6 出力

| ID | 要件 |
|---|---|
| F-50 | 「PNGで保存」ボタンで、元画像の解像度のままモザイクを掛けた画像をPNGでダウンロードできる |
| F-51 | 保存ファイル名は `元のファイル名_mosaic.png`。貼り付けた画像は `mosaic_YYYYMMDD-HHMMSS.png` |
| F-52 | 「クリップボードにコピー」ボタンで、モザイクを掛けた画像をPNGとしてクリップボードにコピーできる |
| F-53 | 保存するPNGには EXIF などのメタデータを含めない（canvas から書き出すため自然に除かれる） |
| F-54 | 範囲の枠線や選択ハンドルは出力画像に含めない |

## 3. 非機能要件

| ID | 要件 |
|---|---|
| N-01 | 処理はすべてブラウザ内で行い、画像を外部に送信しない。画面にもその旨を表示する |
| N-02 | 長辺 4000px 程度の画像でも、範囲の操作中にモザイクの再描画が目立って遅れないこと |
| N-03 | 長辺が 10000px を超える画像は、処理が重くなる旨を警告したうえで読み込む |
| N-04 | ページを閉じたり再読み込みしたりすると、編集内容は破棄される（保存しない）。範囲がある状態でページを離れるときは、ブラウザ標準の確認を出す |

## 4. 画面構成

PC専用。最小幅は 1024px を想定する。

```
┌────────────────────────────────────────────────────────────┐
│ Mosaic Creator          [ファイルを選択]   画像はブラウザ内で処理されます │  ← ヘッダー
├──────────────────────────────────────────┬─────────────────┤
│ ツールバー: [ブロック|グレー]  粗さ ──●── 16px              │                 │
│            （グレー時: [濃|中|淡]）   [↶][↷]           │  範囲一覧        │
├──────────────────────────────────────────┤  #1 ブロック 16px ✕│
│                                          │  #2 グレー 中    ✕│
│                                          │                 │
│            キャンバス（画像表示）              │  [すべて削除]     │
│     未読み込み時: ドロップ／貼り付けの案内          │                 │
│                                          ├─────────────────┤
│                                          │ [PNGで保存]       │
│                                          │ [クリップボードにコピー]│
├──────────────────────────────────────────┴─────────────────┤
│ photo.jpg  3024 × 4032 px                                  │  ← ステータス
└────────────────────────────────────────────────────────────┘
```

- 画像を読み込む前は、キャンバス領域に「ドラッグ＆ドロップ／Ctrl+V で貼り付け／ファイルを選択」の案内を大きく表示する
- 画像を読み込む前は、保存・コピー・一覧の操作を無効にする

## 5. デザイン方針

- 白基調のミニマルなデザイン（Apple / Linear 風と Notion / Figma 風の中間）
- 背景は白〜ごく淡いグレー。パネルは淡いグレーのカードに柔らかい影を付ける
- アクセントカラーはインディゴ系の1色（ボタン、選択状態、範囲の枠線）
- 角丸は大きめ（8〜12px）、線は細く、余白を広く取る
- フォントはシステムフォント（`system-ui`, `"Hiragino Sans"`, `"Yu Gothic UI"`, `"Meiryo"` など）
- ダークモードは作らない

## 6. 操作フロー

1. 画像を読み込む（ファイル選択／ドロップ／貼り付け）
2. ツールバーでモザイクの種類と設定を選ぶ
3. 画像上をドラッグして範囲を指定する（すぐにモザイクが反映される）
4. 必要に応じて範囲を選び、移動・リサイズ・設定変更・削除をする
5. 「PNGで保存」または「クリップボードにコピー」で出力する

## 7. キーボード操作

| キー | 動作 |
|---|---|
| Ctrl+V | 画像を貼り付けて読み込む |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直し |
| Delete / Backspace | 選択中の範囲を削除 |
| Esc | 範囲の選択を解除／ドラッグ中の範囲作成を取り消す |
| Ctrl+S | PNGで保存 |

## 8. ファイル構成（案）

```
mozaic-creator/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js        … 初期化、イベントの接続
│   ├── loader.js      … 画像読み込み（ファイル／ドロップ／貼り付け）
│   ├── editor.js      … キャンバス描画、範囲の作成・選択・移動・リサイズ
│   ├── mosaic.js      … ブロックモザイク／グレー塗りの処理
│   ├── history.js     … 元に戻す／やり直し
│   ├── exporter.js    … PNG保存、クリップボードへのコピー
│   └── ui.js          … トースト、確認ダイアログ
├── docs/
│   └── requirements.md
├── .nojekyll          … GitHub Pages で Jekyll の処理を無効にする
├── LICENSE          … MIT License
└── README.md
```

- JavaScript は ES Modules（`<script type="module">`）で分割する。ビルド工程は設けない
- GitHub Pages は `main` ブランチのルートから公開する

## 9. 対象外

- スマホ・タブレット対応、タッチ操作
- Chrome 以外のブラウザ
- EXIF の向き補正
- 複数画像の一括処理
- 長方形以外の範囲（自由形状、楕円など）
- ぼかし、黒塗りなど、他のモザイクの種類
- 編集内容の保存・再開
- 多言語対応、ダークモード
