# Mosaic Creator

画像の指定した長方形範囲にモザイクを掛けて、PNG で保存できる Web アプリです。
処理はすべてブラウザ内で行われ、画像が外部に送信されることはありません。

## 機能

- 画像の読み込み：ファイル選択／ドラッグ＆ドロップ／クリップボード貼り付け（Ctrl+V）
- 対応形式：PNG / JPEG / WebP / GIF（GIF は1フレーム目）
- モザイクの種類：ブロックモザイク（粗さ 4〜64px）／グレー塗りつぶし（濃・中・淡）
- 範囲は複数指定でき、移動・リサイズ・削除・元に戻す／やり直しができる
- 元画像と同じ解像度で PNG 保存、またはクリップボードへコピー

対応ブラウザは PC 版 Google Chrome です。

## 使い方

1. 画像を読み込む
2. ツールバーでモザイクの種類と設定を選ぶ
3. 画像上をドラッグして範囲を指定する
4. 「PNGで保存」（Ctrl+S）または「クリップボードにコピー」

範囲を選択した状態でツールバーの設定を変えると、その範囲に反映されます。
